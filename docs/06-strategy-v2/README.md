**In one line:** N.E.D becomes the USD wallet for Vietnamese workers abroad, starting with Japan. Its differentiator is a hụi (rotating savings circle) whose pot sits in a Solana smart contract, so no organiser can run away with it. In Vietnam, N.E.D offers only lawful, non-crypto features: a digital hụi ledger, financial education and simulated investing.

**Status:** approved by the project owner; not yet reviewed by a mentor, the Compliance Lead (`../05-legal/compliance-lead-tasks.md`) or a lawyer. Labels in the documents: [Sourced] / [Inference] / [Assumption] / [Unverified].
